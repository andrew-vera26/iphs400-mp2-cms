# CMS field notes (WordPress Playground)

- When I created a new user with the Editor role and logged in as them, I could no longer get to Settings. WordPress's docs say editors can manage content but can't change site settings or add new users, so this matches. The Settings item was gone from the menu entirely, with no error message.
- The first post I wrote went under "My WordPress Website," the default site name. After that I made my own site, which shows in the top right as "Kenyon Political Science." That was a little confusing, because I was just navigating WordPress and did not realize I was already inside my own personal intro site by default.
- I like the "All Posts" tab. It's intuitive and lists everything I've posted so far, and it has links at the top to filter by status, like Published or Draft.
- Every URL was built the same way, and they all had "WordPress" in them. The part that comes from the post's title is called the slug. A real one from my site is https://playground.wordpress.net/scope:confident-hip-state/2026/10/24/new-kenyon/, where "new-kenyon" is the slug.
- I expected to see my post on the public site as soon as I saved it, but I couldn't until I published it. Saving a draft keeps it private.
- The Editor losing access to Settings is not a problem for the Kenyon Model UN club, because it matches the club's rule that editors can't create users or edit each other's recaps.
