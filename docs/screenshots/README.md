# Screenshots

Twelve PNGs of the admin console, each captured at 1280 px and at 390 px wide. Pixel sizes are the image dimensions.

| File | Screen | Width (px) | What it shows |
|---|---|---|---|
| `login-1280.png` | Login | 1280 | The "Log in" form with Email and Password fields and a Log in button. The Email field is focused. There is no navigation bar. |
| `login-390.png` | Login | 390 | The same form at phone width, with the fields stacked below their labels and the Email field focused. |
| `dashboard-1280.png` | Admin dashboard | 1280 | Recap counts by status, Trips, Draft and Published Pages, active Accounts, and the "changes not yet live" notice. |
| `dashboard-390.png` | Admin dashboard | 390 | The same content at phone width. The navigation links wrap onto two lines. |
| `content-list-1280.png` | Admin Recaps list | 1280 | Status, Trip and Owner filters and a table of Recaps with title, Trip, Byline, Owner, status and a Delete button. |
| `content-list-390.png` | Admin Recaps list | 390 | The filters stacked one above another, then the table. The table is cut off at the right edge: Title, Trip, Byline and Owner are visible and Status is partly visible. Actions is not visible. |
| `users-1280.png` | Admin Accounts list | 1280 | Accounts with name, email, class year, role and status, and the Change role, Set password and Deactivate actions. |
| `users-390.png` | Admin Accounts list | 390 | The table is cut off at the right edge: Name, Email, Class and Role are visible and Status is partly visible. The Actions column is not visible. |
| `editor-1280.png` | Recap editor (Editor signed in) | 1280 | A Draft Recap with status, Owner and timestamps, the Trip, Title, Slug and Markdown Body fields, a Preview, the image upload form and a Submit button. |
| `editor-390.png` | Recap editor (Editor signed in) | 390 | The same editor at phone width, with each field on its own line and the rendered Preview shown under the buttons. |
| `editor-denied-1280.png` | 403 page (Editor signed in) | 1280 | The styled "Not allowed" page shown when an Editor opens an Admin-only screen. |
| `editor-denied-390.png` | 403 page (Editor signed in) | 390 | The same "Not allowed" page at phone width. |
